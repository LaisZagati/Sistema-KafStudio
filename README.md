# KAF Studio — Gestão de alunas e mensalidades

Aplicativo de gestão do KAF Studio Pilates.

## Arquivos
- `index.html` — estrutura principal do aplicativo
- `styles.css` — design e estilos
- `core.js` — dados, mensalidades, presença e reposições
- `app.js` — telas e interações
- `logo.svg` — logo oficial do KAF Studio
- `icon-180.png` — ícone para iPhone

O aplicativo também inclui a assinatura discreta **Powered by Digital Studio Co** no rodapé.
